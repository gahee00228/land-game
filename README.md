# 🏰 땅따먹기 배틀! (Land Game)

> 사용자(Player)와 컴퓨터(AI)가 맞붙는 실시간 영토 확장 보드게임! 👑 vs 🤖

---

## 🎮 게임 소개
- **플레이어 vs AI 대전**: 턴 방식으로 영토를 확장하며 더 넓은 땅을 차지하는 플레이어가 승리합니다.
- **다이나믹 사운드 & 비주얼 이펙트**: 차지 효과 애니메이션 및 웹 오디오 효과음 지원.
- **반응형 웹 UI**: 모바일 및 데스크탑 환경 모두 지원.

## 🚀 실행 방법

### 방법 1. 정적 파일 직접 실행
- `index.html` 파일을 더블 클릭하여 브라우저에서 바로 실행할 수 있습니다.

### 방법 2. 로컬 Node.js 서버 실행
```bash
node server.js
```
- 브라우저에서 `http://localhost:3000` 접속

## 🛠️ 기술 스택
- **HTML5**
- **Vanilla CSS3** (반응형, 모던 UI 디자인)
- **Vanilla JavaScript (ES6+)**
- **Node.js** (선택적 로컬 정적 서버용)
